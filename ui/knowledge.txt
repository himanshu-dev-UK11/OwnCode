================================================================================
OWNCODE KNOWLEDGE GUIDE — ui/ (Graphical User Interface, Editor, Dock & Panels)
================================================================================

1. PURPOSE OF THIS FOLDER
-------------------------
The `ui/` folder contains every visual component of OwnCode IDE, consolidated
into 8 cohesive modules:
  • `main_window.py`        : Top-level `MainWindow` orchestrator & `InlineAIController`
  • `shell_and_chrome.py`   : `TitleBar`, `ActivityBar`, `StatusBar`, `ToolBar`,
                              and non-blocking `NotificationCenter` (`_Toast`)
  • `widgets_and_icons.py`  : Shared UI atoms (`IconButton`, `TextButton`, `Card`,
                              `Divider`, `SectionHeader`, `Pill`, `ensure_tooltips`,
                              `restyle_atoms`), vector `icon()` renderer, `DiffView`,
                              and native file dialogs
  • `dialogs_and_palette.py`: Theme-aware `CommandPalette` (File Search `Ctrl+P` &
                              Commands `>`), `SettingsDialog`, `ThemeGallery`,
                              `ChangeReviewDialog`, and `ToolConfirmationDialog`
  • `code_editor_suite.py`  : `CenterPanel`, `Dashboard`, `EditorTabs`, `CodeEditor`,
                              `Breadcrumb`, `BracketMatcher`, `CompletionPopup`,
                              `SyntaxHighlighter`, and `TreeSitterHighlighter`
  • `sidebar_panels.py`     : Left `Sidebar` and all 7 panels (`Explorer`,
                              `SearchPanel`, `GitPanel`, `RunPanel`, `TestPanel`,
                              `TasksPanel`, and `MemoryPanel`)
  • `bottom_dock.py`        : `BottomDock` with interactive `TerminalView`,
                              interactive `OutputView`, and the `Smart Problem Finder`
                              (`ProblemsPanel`)
  • `ai_workspace.py`       : Right-hand `AIWorkspace` (`Chat`, `Edit`, `Agent` modes,
                              streaming markdown bubbles, model selector, context)

2. LIBRARIES USED IN `ui/`
--------------------------
  • PySide6.QtWidgets : `QMainWindow`, `QFrame`, `QWidget`, `QSplitter`, `QTabWidget`,
                        `QPlainTextEdit`, `QTreeView`, `QListWidget`, `QLineEdit`,
                        `QPushButton`, `QToolButton`, `QComboBox`, `QSpinBox`, `QDialog`.
  • PySide6.QtCore    : `Qt`, `Signal`, `QTimer`, `QThread`, `QSize`, `QRect`, `QUrl`.
  • PySide6.QtGui     : `QPainter`, `QColor`, `QFont`, `QFontMetrics`, `QSyntaxHighlighter`,
                        `QTextCursor`, `QKeySequence`, `QShortcut`, `QIcon`, `QPixmap`.
  • ast / re / os     : Instant syntax checking in `ProblemsPanel.scan_code()` and
                        workspace file search in `SearchPanel`.

3. MODULES, CLASSES & FUNCTIONS IN `ui/`
----------------------------------------

[1] ui/main_window.py
    Role: Builds the 3-way horizontal splitter (`Sidebar` | `CenterPanel + BottomDock`
          | `AIWorkspace`), wires all signals and keyboard shortcuts (`F5`, `F6`,
          `Ctrl+P`, `Ctrl+Shift+P`, `Ctrl+B`, `Ctrl+\``), persists theme changes,
          and coordinates `refresh_theme()` across all widgets and popups.
    Classes:
      • _DiffDialog — Shows a unified diff of the proposed rewrite with Apply / Cancel.
        Key Methods: __init__
      • InlineAIController — Coordinates a single Ctrl+K inline edit from trigger to applied diff.
        Key Methods: __init__, trigger
      • MainWindow
        Key Methods: __init__, set_theme_manager, set_lsp_manager, set_project_analyzer, set_workspace_manager, set_chat_engine, set_provider_manager, set_ai_integration, set_llm_optimizer, open_folder, open_command_palette, toggle_sidebar
