================================================================================
OWNCODE KNOWLEDGE GUIDE — tools/ (Explorer, Terminal, Runner, Tester, Theme & Git)
================================================================================

1. PURPOSE OF THIS FOLDER
-------------------------
The `tools/` folder houses all IDE tool engines, File Explorer & workspace
scanning operations, terminal execution, automated testing, theming, and
Git/GitHub integrations:
  • File Explorer, Workspace Scanner & Filesystem Tools (`explorer_and_files.py`):
    - `Explorer` & `_ExcludeProxy`: Lazy-mounted `QFileSystemModel` workspace
      tree view, context menus (New File, New Folder, Rename, Duplicate, Delete,
      Copy Path, Reveal in File Manager), collapse-all action, and recent
      workspace cards.
    - `ProjectScanner`, `TreeBuilder`, `LanguageDetector`, `FrameworkDetector`,
      `DependencyAnalyzer`: Scans workspace folder hierarchies, builds directory
      trees, and detects project languages, frameworks, and dependencies.
    - `FileOperations`: Creates, renames, duplicates, deletes, and reveals
      files/folders safely on disk.
    - `FileWatcher`: Monitors open workspace directories and files for external
      changes.
    - `DeleteGuard`: Protects project roots and system paths from accidental
      deletion.
  • Silent Subprocess & Terminal Engine (`terminal_engine.py`):
    - Prevents external console windows from ever flashing on Windows
      (`CREATE_NO_WINDOW` + `SW_HIDE`, stripping `DETACHED_PROCESS` and
      `CREATE_NEW_CONSOLE`) and provides `HiddenProcess` (a drop-in `QObject`
      replacement for `QProcess`).
  • Code Runner & Smart Program Tester (`runner_and_tester.py`):
    - Executes code in 12+ languages (`RunManager`) with live interactive
      `stdin` streaming to the Terminal tab, and automatically analyzes programs
      (`analyze_program`), generates randomized test inputs
      (`generate_test_inputs`), runs multi-step menu/array/record tests
      (`run_program_test`), and diagnoses errors with 1-line quick fixes
      (`diagnose_error`).
  • Theme, Design System & Settings (`theme_and_settings.py`):
    - Defines all 13 color palettes (`Graphite`, `Slate`, `Matte`, `Clay`,
      `Mocha`, `Midnight`, `Nord`, `Forest`, `Rosé`, `High Contrast`, `Paper`,
      `Dune`, `Mist`), typography/spacing tokens, global QSS generation,
      `ThemeManager`, and persistent JSON `SettingsManager`.
  • Git & GitHub Integration (`git_and_github.py`):
    - Wraps `git` and `gh` CLI commands silently (`GitService` and
      `GitHubService`) for status, staging, commits, branches, push/pull,
      cloning, and GitHub browser authentication.

2. LIBRARIES USED IN `tools/`
-----------------------------
  • PySide6 (QtWidgets, QtCore, QtGui) : `QTreeView`, `QFileSystemModel`,
                                         `QSortFilterProxyModel`, `QMenu`,
                                         `QPalette`, `QColor`, and signals.
  • subprocess / os / sys / shutil     : Hidden process spawning, file/folder
                                         operations, and toolchain detection.
  • threading / queue / time           : Asynchronous stdout/stderr reader threads
                                         in `HiddenProcess` and background workers.
  • re / ast / random / tempfile       : Static code analysis of input prompts/loops
                                         and randomized test input generation.
  • json / copy / pathlib              : Settings persistence (`config/settings.json`)
                                         and workspace path resolution.
