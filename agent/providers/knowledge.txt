================================================================================
OWNCODE KNOWLEDGE GUIDE — agent/providers/ (Local LLM & Cloud AI Providers)
================================================================================

1. PURPOSE OF THIS FOLDER
-------------------------
The `agent/providers/` subfolder manages all connections to Local LLMs and
Cloud AI APIs:
  • Local GGUF & Ollama Execution (`local_providers.py`):
    - `LlamaCppLoader` & `LlamaCppProvider`: Discovers local `.gguf` models,
      automatically spawns `llama-server` silently (`CREATE_NO_WINDOW`), selects
      an open loopback port, and streams OpenAI-compatible chat completions.
    - `OllamaProvider`: Performs fast 200ms TCP socket port checks on `127.0.0.1:11434`,
      lists installed Ollama models, and streams responses without flashing windows.
    - `QwenProvider`: Connects to local Qwen/Ollama or OpenAI-compatible servers.
  • Provider Core Infrastructure (`provider_core.py`):
    - `BaseProvider`, `ProviderConfig`, `ProviderRegistry`, `ProviderFactory`,
      `ProviderDiscovery` (fast `<50ms` local port probe), `ProviderHealth`,
      `ProviderRouter`, `ProviderManager`, and encrypted `SecretStore`.
  • Cloud Provider Adapters (`cloud_providers.py`):
    - `OpenAIProvider`, `AnthropicProvider`, `GeminiProvider`, `GroqProvider`,
      `CerebrasProvider`, `DeepInfraProvider`, `FireworksProvider`,
      `TogetherProvider`, and `CustomProvider`.

2. LIBRARIES USED IN `agent/providers/`
---------------------------------------
  • urllib.request / urllib.error / http.client : Zero-dependency HTTP/SSE
                                                  streaming to LLM servers.
  • socket / subprocess / shutil                : Fast local port probes (`150ms`)
                                                  and hidden `llama-server` /
                                                  `ollama serve` management.
  • json / base64 / hashlib / os                : Provider config serialization
                                                  and encrypted API key storage.
