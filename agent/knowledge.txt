================================================================================
OWNCODE KNOWLEDGE GUIDE — agent/ (AI Workspace Backend, Agents & Intelligence)
================================================================================

1. PURPOSE OF THIS FOLDER
-------------------------
The `agent/` folder contains the complete AI backend of OwnCode IDE, organized
into 8 consolidated backend modules plus 2 specialized subfolders:
  • `agent/providers/` : Local LLM (`llama.cpp`, `Ollama`, `Qwen`) & Cloud Providers
  • `agent/models/`    : Model Catalog, Capability Profiles, Smart Router & Optimizer
  • `chat_and_agents.py`           : `AIChatEngine`, `ConnectionManager`, and
                                     specialized agents (`CoderAgent`, `DebuggerAgent`,
                                     `PlannerAgent`)
  • `context_and_memory.py`        : RAG Context Engine, Token Estimator, Symbol/Import
                                     Graphs, `ProjectMemory`, and `DecisionMemory`
  • `code_intelligence.py`         : `ProjectAnalyzer`, `SymbolIndexer`, `ReferenceIndex`,
                                     `DependencyGraph`, and `ArchitectureDetector`
  • `code_editing.py`              : Multi-file transactional edits (`ChangeSet`,
                                     `DiffGenerator`, `PatchBuilder`, `RollbackManager`)
  • `planning_engine.py`           : Task decomposition, dependency graphs, risk &
                                     complexity analysis (`Plan`, `TaskDecomposer`)
  • `execution_and_verification.py`: Autonomous task scheduler, executor, and
                                     build/test/lint verification loop
  • `tool_engine.py`               : Universal agent tool registry, permissions,
                                     terminal/git tools, and execution history
  • `workspace_tools.py`           : Workspace tools (`FileTool`, `EditorTool`,
                                     `SearchTool`, `ProjectScanner`, `BrowserTool`)

2. LIBRARIES USED IN `agent/`
-----------------------------
  • threading / concurrent.futures : Asynchronous AI streaming, parallel indexing,
                                     and background task execution.
  • ast / re / difflib / hashlib   : Python AST symbol indexing, unified diff
                                     generation, patch validation, and caching.
  • json / pathlib / os / time     : Project memory persistence (`config/`),
                                     workspace scanning, and execution metrics.
  • urllib.request / http.client   : Streaming HTTP/SSE requests to local and
                                     cloud LLM endpoints.
