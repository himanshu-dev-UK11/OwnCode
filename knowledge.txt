OWNCODE IDE v2.0 — MASTER PROJECT KNOWLEDGE & ARCHITECTURE MAP
================================================================================

Welcome to the reorganized OwnCode v2.0 codebase. All 370+ original fragmented
Python files and 280+ legacy history files have been consolidated into 6 clean
top-level folders with ~35 cohesive Python modules. Every folder contains its
own detailed `knowledge.txt` file.
